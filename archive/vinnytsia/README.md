# Архів: Вінницький проєкт (РП 2025/12-07) і старий порівняльник

Винесено з `antares/` 04.11.2026 на запит власника («виділи згадку Вінниці, в архіві їх залиш; виділи старий порівняльник, теж залиш в архіві»). Поточний проєкт — `antares/obj` (один варіант, без посилань на ці матеріали).

| Папка | Що це |
|---|---|
| `antares-maket-rp/` | 3D-макет монтажу за РП 2025/12-07 (колишній `antares/index.html`, `src/`, `build.sh`, `tests/`, `docs/`). |
| `antares-twin-porivnyalnyi/` | Старий 3D-двійник «Вінницький проєкт / наш варіант» на одній сцені (колишній `antares/twin`): розділи, невідповідності РП, фото обстеження, монтаж обох проєктів. `docs/` — лише промт режисерського сценарію монтажу обох проєктів; наші розрахунки й кошториси перенесено в `antares/docs`, розрахунки (Python) — в `antares/calc`. |

Нічого з архіву не використовується у збірці `antares/obj`.
