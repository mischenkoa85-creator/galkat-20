# Антарес — окрема 3D-модель АБК з СЕС (27.10.2026)

Артефакт (приватний): «АБК Антарес · СЕС на даху» — https://claude.ai/artifact/Cty2eEkdxbjHxwKfD9bUW6

- `layout.py` — геометрія АБК і розкладка варіанта К1 дослівно за `antares/twin/calc/v3/abk.py` (без енергетичної частини) → `abk_k1.json`.
  Арка «по даху»: 99 місць = 99 модулів (13 колонок × 9 рядів мінус вентшахти й вентвиходи), схід 46 / захід 53, нахил 0–12,2°.
  Нижній дах «домік» схід–захід 15°: 35 місць, 33 модулі; 2 поза стрінгами — західний схил правої пари, два північні ряди (за рисунком звіту К1).
- `tpl.html` + `build.py` → `index.html` (Three.js r128 з cdnjs, OrbitControls з jsDelivr).
- Цифри К1 (132 = 12 стрінгів, 96,4 кВтп, 88,7 МВт·год, 29 536 $) — зі звіту
  `antares/twin/docs/Розрахунок_радіації_і_розкладки_модулів_на_даху_АБК_…_27.10.2026.pdf`.
- Висоти АБК — оцінка (не міряно): південний блок 10,0 м, карниз основного 13,2 м, стріла 1,3 м, надбудова +12,6 м.
  Кріплення «доміку» показано схематично. Рядки стрінгів не показано: розподіл залишків між стрінгами залежить від енергії модулів.
