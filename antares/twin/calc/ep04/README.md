# Електрика, блискавкозахист, кріплення і баласт — два етапи (аналіз 04.11.2026)

Запит власника 04.11 (04:09): «міркуй стосовно блискавкозахисту, розводки електрики, кількості кабелів, лотків, кріплень, металу, метизів, робіт, баласту, щитів, стрінгів — найкраще рішення з найменшими втратами; глибокий аналіз», далі (04:31) «роби далі до кінця».

Порядок запуску (у цій папці; `data.json` і `wx.json` — експорт із двійника: roof28 В1, ліхтарі, фасади, склад варіанта Б, контейнери, погода):
1. `python3 ep_opt.py` — щити даху з розкладки В1, щити ліхтарів, фасадів, складу; τ = Σ(G/1000)²Δt = 551 год.
2. `python3 merge.py` — малі щити даху: перенесення кінців стрінгів (29 → 28) → `rb_merged.json`.
3. `MERGED=1 python3 run_opt.py` — сценарії розподілу і перерізу; `MERGED=1 python3 final.py` — рекомендований (Л4 → К-1, ≤ 12 входів на контейнер, du ≤ 2,5 %), лотки → `final.json`.
4. `MERGED=1 python3 bom.py` → `bom.json` (кількості, вартість, люд.год, маси, втрати); `python3 wind.py` → `wind.json`.
5. `python3 xlsx_build.py` + recalc → Excel «Кошторис_і_специфікація_СЕС_і_УЗЕ_Антарес_по_етапах_04.11.2026»; `python3 est_pdf.py`, `MERGED=1 python3 fig.py`, `MERGED=1 python3 report.py`, `python3 wind_pdf.py` — PDF.

Результат: К-3, К-1 (ТП-5913) — фасади, склад, ліхтар Л4, схід даху; К-4, К-5 (ТП-6923) — ліхтарі Л1–Л3, захід даху; 42 лінії, Al 120 (одна — 185), ≈8 200 м жил; кабельні втрати ≈1,2 %. Під ключ: етап 1 ≈1 508 000 $, етап 2 ≈439 600 $ без ПДВ. Вітер: баласт ≈27 кг/м² тримає c_net ≤ 0,21 — блоки не зменшувати, потрібні коефіцієнти системи (таблиця чутливості в PDF). У двійнику — `src/elec04data.js` + `src/elec04.js`, кнопка «Електрика».
