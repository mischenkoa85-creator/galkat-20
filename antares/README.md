# Антарес — СЕС і накопичувачі (ТОВ МК «Антарес», Київ, вул. М. Василенка, 1-А)

Один проєкт, без варіантів, у два етапи:

- **Етап 1:** АБК (132 модулі), фасади (максимальна розкладка), модулі на ліхтарях під ≈45°, склад (176); накопичувачі — 4 контейнери Golen LES-H20 (500 кВт / 1 205 кВт·год), по 2 на ТП: К-3, К-1 біля ТП-5913 (паралельно будівлі), К-4, К-5 біля ТП-6923 (на бермі +1,8 м).
- **Етап 2:** дах цеху, розкладка В1 з проходами (1 826 модулів), після нової мембрани.

Вітер — за ДБН; додатковий баласт — лише по краях поля, у середині додаткового баласту немає.

## Сторінки

| Папка | Що це |
|---|---|
| `obj/` | **3D-двійник усього об'єкта** — розділи «Об'єкт», «Сонце і генерація», «Накопичувачі»; стан модулів на вибраний час, генерація за добу і накопичено з ранку, радіація за рік на м², контейнери, електрика, 3 варіанти підключення АБК. Опис — `obj/README.md`, шаблон меню — `obj/Шаблон_3D-двійника_СЕС_і_УЗЕ.md`. Сайт: https://mischenkoa85-creator.github.io/galkat-20/antares/obj/ |
| `abk/` | Модель і розрахунки АБК (розкладка, стрінги Deye, кріплення, кошторис). Модель АБК вставляється в `obj`. |
| `roof/` | Ранній 3D дах цеху (сонце, тіні, проходи, генерація по годинах і місяцях). |
| `calc/` | Розрахунки (Python): розкладки, радіація, тіні, фасади, ліхтарі, електрика `ep04/`, вітер, кошториси. |
| `docs/` | Наші документи: розрахунки (PDF), кошториси (XLSX + PDF), креслення розкладки. |

## Збірка двійника

```
cd antares/obj && ./build.sh   # src/ → index.html
```
