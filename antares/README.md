# Антарес — 3D-макет монтажу СЕС + УЗЕ

Інтерактивний 3D-макет дахової СЕС ТОВ МК «Антарес» (м. Київ, вул. М. Василенка, 1-А):
1022 кВтп, УЗЕ 3,9 МВт·год, проєкт РП 2025/12-07.

**Сайт: https://mischenkoa85-creator.github.io/galkat-20/antares/**

**Нове (23.10.2026): дах у 3D — сонце, тіні, проходи, генерація, варіанти Б і А:** https://mischenkoa85-creator.github.io/galkat-20/antares/roof/ (папка `roof/`, опис у `roof/README.md`).

**3D-двійник (25.10.2026): Вінницький проєкт і наш варіант Б на одній сцені, невідповідності РП, генерація за місяці й рік:** https://mischenkoa85-creator.github.io/galkat-20/antares/twin/ (папка `twin/`, опис у `twin/README.md`).

Або відкрийте `index.html` у браузері (three.js r128 підтягується з CDN).

## Інтерфейс
3D-модель угорі, панель даних унизу (тягнеться за смужку: мала / половина / повна; на телефоні — те саме). Вкладка «Сонце»: година, висота й азимут сонця, потужність станції в кВт і перемикач Зима/Весна/Літо/Осінь — над моделлю. Підписи на об'єктах зменшуються й спрощуються при віддаленні (повний → назва → лише важливі).

## Вкладки
- **Макет** — шари, режим «Зовні / Всередині (схема)» для УЗЕ, варіант УЗЕ (шафи за проєктом / контейнери LES-H20 ×3 — перемикач над моделлю), прив'язка.
- **Деталізація майданчика** (src/site3d.js) — вікна, ворота й цоколь цеху, ТП (двері, жалюзі, заземлення), дріт блискавкозахисту на тримачах, затискачі спусків, колодязі заземлювачів, стовпчики біля УЗЕ; усе схематично.
- **Монтаж** — 13 кроків; елементи кожного кроку з'являються по черзі (мати й баласт, трикутники й сполучники, потім окремий крок кріплення: гвинти R-LX до блоків і болти М8; профілі з прорізами, блоки по краях бази за АБ арк. 6).
- **Сонце** — тіні за датою/часом, орієнтовна генерація в кВт (діапазон і ±15 %), діаграми по сезонах і місяцях.
- **Вузол** — клік по модулю/трикутнику/баласту: розбір на елементи в 3D, креслення, розводка до ЩР-PV → MS → ТП.
- **Записка** — пояснювальна записка, варіанти накопичувача (шафи/контейнер), список панелей, приєднання/ТП, орієнтовні кошториси в євро; курс змінюється в полях угорі.
- **Дані** — зведені таблиці, документи і посилання на джерела.

## Збірка
```
./build.sh   # src/ → index.html
```
Джерела: `src/part1.html` (розмітка/CSS), `src/part2.js` (сцена), `src/ess3d.js` (деталізація майданчиків УЗЕ: шафи АКБ, контейнер, навіс), `src/part3.js` (кроки, сонце), `src/node.js` (вузол), `src/energy.js` (генерація), `src/note.html` і `src/note.js` (вкладка «Записка» і перерахунок за курсом), `src/data.json` (геометрія з проєкту).

## Обмеження
- Положення метизів на 3D схематичні.
- Кліматичні норми Києва наближені — уточнити за PVGIS/Meteonorm. Температурний коефіцієнт прийнято (−0,30 %/°C).
- Річна оцінка ≈ 1125 МВт·год (≈ 1101 кВт·год/кВтп, ±8 %), приблизно на 5 % нижче за PVsyst проєкту (1183 МВт·год).
