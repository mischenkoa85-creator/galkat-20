# Антарес — 3D-макет монтажу СЕС + УЗЕ

Інтерактивний 3D-макет дахової СЕС ТОВ МК «Антарес» (м. Київ, вул. М. Василенка, 1-А):
1022 кВтп, УЗЕ 3,9 МВт·год, проєкт РП 2025/12-07.

**Сайт: https://mischenkoa85-creator.github.io/galkat-20/antares/**

Або відкрийте `index.html` у браузері (three.js r128 підтягується з CDN).

## Вкладки
- **Макет** — модель даху, обстановка, пошук зауважень.
- **Монтаж** — 12 кроків; елементи кожного кроку з'являються по черзі (спочатку мати й баласт, потім трикутники й сполучники).
- **Сонце** — тіні за датою/часом, орієнтовна генерація в кВт (діапазон і ±15 %), діаграми по сезонах і місяцях.
- **Вузол** — клік по модулю/трикутнику/баласту: розбір на елементи в 3D, креслення, розводка до ЩР-PV → MS → ТП.
- **Записка** — пояснювальна записка, варіанти накопичувача (шафи/контейнер), список панелей, приєднання/ТП, орієнтовні кошториси в євро; курс змінюється в полях угорі.
- **Дані** — зведені таблиці.

## Збірка
```
./build.sh   # src/ → index.html
```
Джерела: `src/part1.html` (розмітка/CSS), `src/part2.js` (сцена), `src/part3.js` (кроки, сонце), `src/node.js` (вузол), `src/energy.js` (генерація), `src/note.html` і `src/note.js` (вкладка «Записка» і перерахунок за курсом), `src/data.json` (геометрія з проєкту).

## Обмеження
- Положення метизів на 3D схематичні.
- Кліматичні норми Києва наближені — уточнити за PVGIS/Meteonorm. Температурний коефіцієнт прийнято (−0,30 %/°C).
- Річна оцінка ≈ 1125 МВт·год (≈ 1101 кВт·год/кВтп, ±8 %), приблизно на 5 % нижче за PVsyst проєкту (1183 МВт·год).
