# ГалКат · площадка 20

Інтерактивна 3D-модель і комплект креслень для розміщення установки зберігання енергії
1,725 МВт / 5 МВт·год (контейнер BESS і блок PCS з трансформатором 6 кВ).

**Статус: ескіз, не для будівництва.** Робочу документацію і розрахунки виконує проєктувальник.

## Що тут є

| Файл | Що це |
|---|---|
| `index.html` | 3D-модель: контейнери, фундаменти, кабельний канал, двері. Клік по об’єкту відкриває його креслення |
| `Kreslennya_GalKat_ploshchadka_20.pdf` | Креслення, 4 аркуші A3: план розміщення, схема відчинення дверей, фундамент контейнера BESS, 3D-вигляди |
| `sheets/` | Ті самі аркуші як зображення (їх показує модель) |
| `vendor/` | Бібліотека three.js r128 (ліцензія MIT) |
| `src/draw.py` | Скрипт, що генерує PDF (Python, reportlab) |

## Звідки дані

- Геометрія контейнерів, відступи, двері контейнера BESS і тип фундаменту — довідкові креслення
  виробника Golen Power Technology (Annex 1 до Response 1).
- Двері блока PCS — ширини зняті з масштабу креслення виробника, кут відчинення не вказано.
- Фундамент блока PCS показано умовно: виробник його креслення не надав.
- Кабельний канал і кабелі в ньому — попередній розрахунок, а не дані виробника.

## Як оновити PDF

```
python3 src/draw.py Kreslennya_GalKat_ploshchadka_20.pdf src
```

Потрібні пакет `reportlab` і шрифт DejaVu Sans Condensed.
